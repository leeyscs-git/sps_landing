# 서비스 사례 변경 전 보관본

2026-10-08에 서비스 사례 페이지를 인사이트 공통 구성으로 전환하기 전의 HTML·CSS·JS입니다.

- `original-source.html`: 변경 전 HTML 원문.
- `jll-remix-cases.html`: 브라우저에서 실행할 수 있는 보관 페이지. 원문에 루트 기준 `<base>`와 이 폴더의 CSS·JS 경로, 검색 제외 메타 태그만 추가했습니다.
- `jll-remix-cases.css`, `jll-remix-cases.js`: 변경 전 전용 스타일과 분류 코드 원본.

공통 헤더·파운데이션·상담 창·로고는 프로젝트의 현재 공유 파일을 사용합니다. 이전 페이지 구성과 전용 코드는 이 폴더에 유지되므로, 현재 서비스 사례 코드를 수정해도 보관본에는 반영되지 않습니다.

실행 경로:

- 보관본: `/briefing/service-cases-v1-reference/jll-remix-cases.html`
- 이전·현재 비교: `/jll-remix-cases-compare.html`

비교 화면에서 나란히 보기, 이전만 보기, 현재만 보기와 PC·모바일 화면 크기를 선택할 수 있습니다. 전체 시안 비교 페이지에도 링크가 있습니다.
