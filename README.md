## F안 — 브랜드 메인과 문제별 서비스 설명 (2026-10-01)

후속 G안(2026-10-02)은 공감 → 반복 부담 → 상황 체크 → 설립 경험 → 관리 방식 → 보고 예시 → 범위·비용 → 절차·FAQ → 상담 신청 순서를 사용합니다. 현재 G는 `g-service.html?service=management`(부동산 자산관리)와 `?service=leasing`(임대 운영관리) 두 서비스로 구성됩니다. 기존 `?service=arrears`도 통합 자산관리 상세로 연결됩니다. 체크한 고민이 폼으로 이어지며 입력 → 내용 확인 → 수정이 동작합니다. 접수 경로는 아직 미확정이며 실제 저장·전송·예약은 없습니다. 상세 기록은 [G 적용 기록](briefing/G-APPLICATION.md)을 참조하세요. 전체 비교에 G와 C·G/F·G 보기를 추가했고, F와 G의 상세는 `/g-compare.html`에서 같은 크기로 비교할 수 있습니다.

메인의 큰 사진, 슬라이드, 지구 배경, 스크롤 타임라인은 C의 표현을 재사용합니다. 건물 관리·미납 대응·임차·공실 관리 중 하나를 누르면 해당 문제의 상황 → 맡길 일 → 보고 예시 → 비용·책임 범위 → 상담 절차 안내로 이동합니다. 현재 데이터가 없는 공실 예시는 임의의 실적 대신 자료 확인 전 상태를 보여줍니다.

서비스 이동, FAQ, 보고 근거와 준비 자료 안내, 닫기 후 읽던 버튼·위치 복귀는 실제 동작합니다. 상담은 안내까지이며 신청·저장·전송 기능은 없습니다. 월간 보고서와 앱, 실제 서비스 조건은 제공 계획 또는 확정 전으로 표시합니다. 기존 C·E와 공유 예시 데이터는 보존했습니다.

F 비교는 `cf`, `ef`, `f` 보기 및 전체 7개 보기를 지원합니다. 프레임 안에서 상세 페이지를 읽을 수 있습니다. 과거 안과 문구·제공 내용이 달라 컨셉의 전환 효과만을 검증하는 대조 실험은 아닙니다. 적용 기준은 [CONCEPT.md](CONCEPT.md), 표현 조정은 [DESIGN-ADAPTATIONS.md](DESIGN-ADAPTATIONS.md), 검증과 남은 사항은 [06 결정 카드](briefing/06-DECISION-CARD.md)에 기록합니다.

비교 화면은 전체 원본·A·B·C·D·E 보기, A·B / B·C / C·D / B·E / C·E / D·E 나란히 보기, 원본 및 각 시안 단독 보기를 지원합니다. `?view=ce` 등으로 특정 조합을 바로 열 수 있습니다. 데스크톱 1280×900px와 모바일 390×844px의 동일한 논리 해상도로 렌더링한 뒤 가로 공간에 맞춰 축소합니다. 화면 높이에 반응하는 C안의 모션도 같은 조건으로 비교할 수 있으며, iframe 안에서 각각 스크롤할 수 있습니다. 전체 비교는 601~1600px 화면에서 2열, 더 넓은 화면에서 3열로 표시합니다. 원본 HTML은 변경 전 Git 버전에서 그대로 복원했으며 기존 스타일과 컴포넌트를 사용합니다. ## 디자인

A는 사용자 제공 `DESIGN-mastercard.md`의 크림 배경, 원형 이미지, 40px 미디어 프레임, 오렌지 궤도선을 적용한 이전 시안입니다. 이전 시안의 레이아웃과 동작을 보존하고, 시안 전환 링크 및 사용자 요청에 따른 에셋 로고를 적용했습니다.

B는 https://www.jll.com/ko-kr/ 의 2단 헤더, 전체 폭 도시 사진, 주요 스토리 선택 영역, 사진과 설명의 교차 배치, 직선적인 콘텐츠 구성을 참고했습니다. 흰색과 짙은 청록색 텍스트, 레드 포인트를 사용하며 SPS 브랜드와 자체 작성 콘텐츠를 유지합니다.

세 버전 모두 검색, 서비스·기사 상세 모달, 건물 진단, 모바일 메뉴를 제공합니다. A·B는 인사이트 필터와 FAQ를 포함하고, B는 4개 스토리의 이전/다음 전환을 지원합니다. C는 아래 모션 중심의 별도 구성을 사용합니다.

건물 진단은 선택한 건물 유형·규모·관리 고민에 대한 참고 가이드를 브라우저에서 생성합니다. 서버 전송, 개인정보 수집, 실제 상담 접수 기능은 없습니다. 인사이트 본문은 시안용 예시 콘텐츠입니다.

## C안 모션 구성

레퍼런스: https://www.hyosung.com/kr/index

효성의 공개 `resources/kr/js/page/main.js`, 메인 스타일시트 및 실제 화면을 대조해 전환 방향, 재생 시간, 스크롤 구간을 반영했습니다. SPS 콘텐츠와 로고는 유지합니다. CSS, Web Animations API, IntersectionObserver와 requestAnimationFrame을 사용합니다.

- 히어로: 5초 진행 후 1초 가로 전환, 이미지 30% 패럴랙스, 1.2→1 배율의 5초 줌. 제목은 전환 종료 후 30px 아래에서 0.75초 등장하며 캡션은 0.2초 늦게 따라옵니다.
- 이전/다음/일시정지. 키보드 포커스·모달 열림·화면 밖·비활성 탭에서는 자동 전환을 멈춥니다.
- 서비스 카드: 상하 선은 0.4초, 구분선은 0.7초 동안 원본의 지연 간격으로 그립니다. 호버/포커스 때 연한 빨간 배경, 제목 세로 교체, 40px 아래에서 설명 등장, 화살표 교체를 적용합니다. 모바일에서는 설명을 항상 표시합니다.
- 연결된 배경: 고정 지구 영상, 스크롤에 따른 0.9→0.75 축소(모바일 1→0.95), 10px 흐림, 배경 100px 이동을 적용합니다. 영상은 섹션이 화면 근처에 있을 때만 재생됩니다.
- 핵심 솔루션 3개 / 도입 과정 4단계 / 공통 목표 1개의 카운트업. 고객 수나 운영 실적을 의미하는 수치는 아닙니다.
- 도입 과정: 300svh의 구간에서 화면을 고정하고 세로 스크롤을 가로 카드 이동에 연결합니다. 설명 사라짐 → 카드 이동 → 고정 해제 순서와 원본의 구간 비율을 적용합니다. 카드 호버/포커스는 중앙에서 전체 이미지가 0.5초 동안 펼쳐집니다. 이전/다음 버튼과 좌우 방향키도 지원합니다.
- 숫자는 10%에서 시작해 1초 동안 목표 값까지 증가합니다. 페이지 스크롤은 기본 입력을 사용하고 장식 레이어만 짧게 보간하므로 이동이 누적되지 않습니다.
- `prefers-reduced-motion`에서는 자동 재생과 움직이는 효과를 줄이고 내용을 즉시 표시합니다. 스크롤 입력을 가로채지 않습니다.

A·B의 HTML/CSS/JS는 C안 작업에서 변경하지 않았으며, 공통 버전 전환 UI와 비교 화면에만 C 옵션을 추가했습니다.

### H 디자인 문서에서 직접 편집

`/jll-remix-design-system.html`의 각 **값 조정**에서 색상·치수 등을 바꾸면 H 메인에도 자동 반영됩니다. 변경값은 `design/jll-remix/theme.json`에 자동 저장되며 새로고침 후에도 유지됩니다. 항목별 기본값과 전체 기본값 복원을 제공합니다. 다른 시안과 별도 H 소개 스타일은 그대로 유지됩니다.

`npm run dev` 또는 `npm start`는 로컬 디자인 저장 서버(127.0.0.1:3001)와 정적 미리보기(127.0.0.1:3000)를 실행합니다. 3000에서 기존 미리보기가 이미 실행 중이면 유지합니다. 저장 실패는 문서 상단에 미저장으로 표시합니다. 일반 정적 서버만 실행해도 저장된 설정은 읽지만 새 값을 저장하려면 이 디자인 서버가 필요합니다.

`npm run test:theme`로 저장·입력 제한·동시 변경·복원·출처 제한 검사를 실행할 수 있습니다. 자세한 범위와 구현 관계는 [H 디자인 문서](design/jll-remix/design.md)의 Edition 03에 있습니다.
