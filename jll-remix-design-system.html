CORE LAYOUT RULE / 최우선 정렬 기준

사진을 제외한 모든 콘텐츠는
헤더의 좌우 정렬선 안에 둡니다.

제목·본문·브레드크럼·표·버튼·픽토그램·푸터까지 같은 경계를 사용합니다. 본문 폭은 더 좁아도 되지만, 헤더보다 넓어지지 않습니다.

적용 기준 · 파운데이션의 ‘본문 최대 너비’와 ‘좌우 여백’을 함께 사용합니다. 사진 위 문구·버튼과 아이콘은 확장 예외에 포함되지 않습니다. 모바일도 같은 화면의 헤더 기준을 따르며, 넓은 표는 경계 안에서 가로 스크롤합니다. 애니메이션 중에도 정보가 경계를 넘지 않게 합니다.

C.02 / HEADER & NAVIGATION

헤더·내비게이션

브랜드, 문의 입구, 주요 메뉴의 두 줄 구성.
로고 옆 슬로건은 제거하고, 메뉴 오른쪽에 대한민국·KO 선택을 배치했습니다. 햄버거 메뉴는 모바일에서만 표시합니다.

DESKTOP / 축소된 문서 폭의 견본.nav-shell · .header-contact

1상단 87px 로고 + 문의

2메뉴 49px 현재 위치는 빨강, 호버·펼침은 연한 구분선 회색

3모바일 75px 로고 + 문의 + 펼침 메뉴

메뉴 간격은 원본 B와 같은 34px, 850px 이하에서는 27px입니다. V1은 부동산 자산관리·임대 마케팅·실내건축 세 항목을 표시합니다. 임대관리·시설관리·회계정산대행은 부동산 자산관리 설명에 묶습니다. 앞에 “어떤 서비스가 필요하신가요?”를 두고, 이름과 짧은 설명, 가는 구분선으로 구성합니다. V1은 서비스 이름과 설명을 먼저 보여주고, 배경 없는 작은 픽토그램을 각 항목 오른쪽 아래에 둡니다. 넓은 PC 메뉴에서는 질문의 자연스러운 줄 높이 1.5를 유지하고 “필요하신가요?”와 서비스 설명 마지막 줄의 글자 기준선을 맞춥니다. 제목·설명 사이 6px 여백 때문에 질문의 행간을 늘리지 않습니다. V1·V4의 SERVICES 라벨은 제거하고 질문에 브랜드 빨강을 적용합니다. 서비스별 화살표는 기본 보조 회색(Muted)이며 항목 호버·키보드 초점에서 빨강(Red)으로 바뀝니다. 서비스 제목은 기본 잉크색이며 호버·키보드 초점에서만 빨강으로 강조합니다. 넓은 PC의 V1·V4에서는 제목과 설명이 호버·키보드 초점에서 같은 250ms 전환으로 함께 오른쪽 2px 이동해 세로 정렬을 유지합니다. 둘 사이 간격과 항목 크기는 유지합니다. 현재 부동산 자산관리의 제목·설명은 이동하지 않으며 화살표 효과는 유지합니다. 세 서비스의 픽토그램은 모두 호버·키보드 초점에서도 움직이지 않습니다. 그림 크기·위치·배치 공간을 고정하고 나머지 문구와 화살표의 현재 호버 효과는 유지합니다. 화살표만 오른쪽 위 2px·200ms로 이동하며 포인터가 벗어나면 같은 전환으로 복귀합니다. 서브메뉴 화살표는 16px 크기로 고정하고, 200ms 위치 전환을 사용해 정지 시 그리기 방식이 바뀌는 영향을 줄입니다. SVG 선 굵기는 기본·호버에서 동일합니다. 움직임 감소 설정에서는 이동 없이 색상으로 상태를 표시합니다. 제목 위 여백은 56px에서 40px로 줄였습니다. 넓은 PC에서 질문과 서비스 묶음 사이 간격은 28px에서 64px로 넓히고, 남은 영역은 세 서비스가 같은 비율로 나눕니다. 1100px 이하에서는 안내를 별도 행으로 배치하고 간격 28px를 유지합니다. 현재 메뉴 밑줄은 파운데이션 Red(--red), 호버·초점·펼침 밑줄은 구분선(--line)을 공유합니다. 현재 메뉴에 호버해도 빨강을 유지합니다. 모바일에서는 현재 메뉴는 Red, 탐색 중인 메뉴는 읽기 쉬운 Muted를 사용합니다. V1은 기존의 얇은 선형 스타일로 각 서비스의 의미를 보완했습니다. 자산관리는 건물과 운영 기록, 임대 마케팅은 임대 공간과 확성기, 실내건축은 실내 구조·가구·롤러로 표현하며 설명은 “인테리어 · 리모델링 · 공간개선”으로 표시합니다. V4는 제공된 문서·안내서 레퍼런스의 굵은 윤곽선과 붉은 면을 적용한 벡터 픽토그램입니다. 두 안 모두 PC 96px·모바일 80px, 배경·바닥선 없이 배치합니다. 잉크색·강조색은 파운데이션과 연결합니다. 메뉴 하단 여백은 40px, 항목 최소 높이는 208px입니다. 설명 아래 패딩은 20px이며 모바일에서는 16px입니다. 항목을 선택하면 H의 해당 업무 설명으로 이동합니다. V2·V3는 기존 네 가지 업무 분류를 비교용으로 보존합니다. V2 트윅은 기존 SPS 사이트의 서비스명 → 설명 → 세부 업무 구성을 사용합니다. V3 트윅은 초기 메뉴의 안내 문구와 연한 배경의 픽토그램 카드를 재현합니다. 서비스 옆 화살표는 오른쪽을 향하다 메뉴가 열리면 240ms 동안 아래로 회전합니다. 포인터가 메뉴 밖으로 나가면 대기 없이 220ms 동안 페이드아웃합니다. 사라지는 도중 다시 진입하면 현재 밝기에서 페이드인으로 이어집니다. 완전히 닫힌 메뉴를 열 때 질문은 8px 아래에서 420ms 동안 부드럽게 나타나며, 최종 기준선은 유지합니다. 키보드는 Enter·아래 화살표로 열고 Escape로 닫습니다.

H 메인에서 확인한 표현을 정리한 SPS 작업용 문서입니다. JLL 공식 가이드가 아닙니다. 문서용 주석·목차·확대 도식은 제품 컴포넌트가 아니며, SPS 소개는 메인과 공통 헤더·푸터를 사용하고 본문에는 별도 스타일을 사용합니다. 파운데이션을 조절하면 공통 헤더·푸터에 함께 반영됩니다.
